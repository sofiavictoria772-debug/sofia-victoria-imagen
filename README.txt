SOFÍA VICTORIA IMAGEN - WEB

Archivos:
- index.html
- styles.css
- script.js

Cómo verla:
1. Abrir index.html en Chrome, Edge, Safari o Firefox.
2. Para publicar, subir los 3 archivos a un hosting (Netlify, Vercel, GitHub Pages, etc.).

Pendientes recomendados antes de publicar:
- Reemplazar el bloque “Tu foto profesional” por una foto real.
- Agregar número de WhatsApp al botón de contacto.
- Agregar testimonios reales y/o portfolio.
- Confirmar paquetes, precios y modalidad de cada servicio si se desea mostrar.
